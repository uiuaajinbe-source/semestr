PostureChecker - приложение для контроля положения осанки пользователя в реальном времени с использованием веб-камеры и алгоритмов компьютера. Программа определяет ключевые точки тела, их положение
и помогает фиксировать правильное положение  спины и шеи во время работы за компьютером.
Цель: создать быстрое и эффективное приложение на C++, которое предупреждает пользователя о неправильном положении спины, минимизируя задержки за счет оптимизации и современной нейросетевой модели.
Язык программирования: С++
Компьютерное зрение: OpenCV
Нейросетевая модель: YOLOv8-pose(format ONNX)
Менеджер пакетов: vcpkg
Среда разработки: Visual Studio
Контроль версий: Git + GitHUb
Основные функции:
  1.Захват ключевых точек. Определение точек плеч, ушей, и позвоночника с помощью модели "YOLOv8-pose"
  2.Анализ геометрии осанки. Расчет углов наклона головы и отклонения спины относительно правильного положения
  3.Оповещение. Графические и звуковые сигналы, предупреждение чтобы пользователь выпрямился
